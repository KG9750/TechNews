# Push low-confidence items with visible confidence notices

Status: accepted

The product will run fully automatically and may push lower-confidence but potentially important briefing items. Instead of hiding these items, excluding them by default, or requiring manual review, the Push Briefing must show a visible Confidence Notice with supporting sources and uncertainty. This preserves awareness of emerging stories while making uncertainty explicit enough that recipients do not mistake every pushed item for equally verified news.

**Consequences**

- Push Briefing layouts must reserve space for Confidence Notices.
- Archive Metadata must retain the source evidence and Selection Rationale behind each notice.
- Quality review should track whether low-confidence pushed items are useful or erode trust over time.
