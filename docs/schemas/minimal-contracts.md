# Minimal Contracts

Status: Draft
Last updated: 2026-06-01

These contracts are the shared input for Feishu, model, archive, and source spikes. They are intentionally minimal and will later be converted into JSON schemas.

## Shared Conventions

- `run_id` is required on every run-owned object.
- IDs are stable strings generated by the application.
- Timestamps use ISO 8601 UTC.
- Source text bodies are not stored by default.
- URLs must point to source pages, official assets, or generated archive files.

## CandidateItem

Minimum fields:

| Field | Required | Notes |
| --- | --- | --- |
| `id` | yes | Stable candidate identifier. |
| `run_id` | yes | Briefing run that discovered or considered the item. |
| `source_id` | yes | Source registry identifier. |
| `source_type` | yes | `public_feed`, `academic_source`, `manual_url`, or `deferred_connector`. |
| `source_name` | yes | Human-readable source name. |
| `original_title` | yes | Title as published by the source. |
| `source_url` | yes | Original Source Anchor URL. |
| `published_at` | no | Source publication time when available. |
| `discovered_at` | yes | Time the system found the item. |
| `language` | no | Source language when detected. |
| `section_hints` | no | Candidate Briefing Sections before classification. |
| `source_media` | no | Source Media metadata when available and eligible. |
| `eligibility_state` | yes | `eligible`, `needs_review`, `deferred`, or `blocked`. |
| `eligibility_notes` | no | Storage, rate limit, media, or access notes. |
| `raw_metadata` | no | Small source metadata only; no full article body. |

## BriefingItem

Minimum fields:

| Field | Required | Notes |
| --- | --- | --- |
| `id` | yes | Stable briefing item identifier. |
| `run_id` | yes | Run that generated the item. |
| `candidate_id` | yes | Selected CandidateItem. |
| `section` | yes | Briefing Section. |
| `subcategory` | no | Section Subcategory. |
| `title_zh` | yes | One-sentence Chinese briefing title. |
| `bullets_zh` | yes | Three to four concise bullets. |
| `original_source_anchor` | yes | Original title and source URL. |
| `selection_rationale` | yes | Human-readable inclusion and ranking reason. |
| `confidence_level` | yes | `high`, `medium`, or `low`. |
| `confidence_notice` | no | Required when confidence is not high. |
| `media_attribution` | no | Required when source media is used. |
| `related_history` | no | Lightweight links to earlier archived items. |

## ArchiveMetadata

Minimum fields:

| Field | Required | Notes |
| --- | --- | --- |
| `run_id` | yes | Archive package run id. |
| `domain_template` | yes | Example: `technology`. |
| `generated_at` | yes | Archive creation time. |
| `files` | yes | Paths for `briefing.html`, `briefing.md`, `metadata.json`, and media. |
| `selected_items` | yes | BriefingItem ids. |
| `excluded_candidates` | yes | Candidate ids with Selection Rationales. |
| `connector_status` | yes | Source Connector completion, timeout, or failure state. |
| `delivery_status` | yes | Per Briefing Recipient delivery state. |
| `media_inventory` | yes | Source media used and attribution state. |
| `sync_status` | yes | Local and NAS/cloud sync state. |
| `model_usage_summary` | yes | Request counts, token usage when available, latency, and failures. |
| `warnings` | no | Run-level warnings. |

## BriefingRun

Minimum fields:

| Field | Required | Notes |
| --- | --- | --- |
| `run_id` | yes | Stable run identifier. |
| `domain_template` | yes | Domain Template processed by the run. |
| `scheduled_for` | yes | Intended schedule time. |
| `delivery_deadline` | yes | Cutoff for Push Briefing delivery. |
| `started_at` | yes | Run start time. |
| `completed_at` | no | Run completion time. |
| `connector_status` | yes | Per Source Connector status. |
| `model_task_status` | yes | Per model task status and usage metadata. |
| `archive_status` | yes | Archive write and sync status. |
| `feishu_delivery_status` | yes | Per recipient delivery result. |
| `run_warnings` | no | Late connectors, low-confidence pushes, or sync failures. |

## Spike Requirement

Every spike must use these field names unless it documents a required change. If a spike needs a new required field, update this document before implementation issues are created.
